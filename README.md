## 这是什么

一个给自己和朋友用的 Minecraft 启动器。

装游戏、开游戏这两件事,尽量不让你操心:**你只管点开始,剩下的交给 NannyCraft。**

> 首个正式版还在打磨中,暂未提供下载;发布后会在这里补上。
